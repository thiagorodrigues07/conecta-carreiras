# Conecta Carreiras

Site estático acadêmico que apresenta oportunidades de estágio, jovem aprendiz e cursos para quem está começando em tecnologia.

## Tecnologias

HTML5, CSS3 e imagens SVG. Não utiliza framework.

## Como executar

Abra `index.html` em um navegador. O site não precisa de instalação nem servidor.

## Exemplo de uso

Use a navegação para consultar as páginas Início, Oportunidades, Sobre e Contato.

## Objetivo de aprendizagem

Praticar HTML semântico, navegação entre páginas, CSS responsivo e acessibilidade básica.

## Publicar com GitHub Pages

Em **Settings → Pages**, escolha **Deploy from a branch**, selecione `main` e `/(root)`. Depois do primeiro deploy, o site ficará em https://thiagorodrigues07.github.io/conecta-carreiras/.
